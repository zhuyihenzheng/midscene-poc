## 判定の読み方

- **NG（不一致）**：値は取得できたが期待値と違う。不具合の候補（`不具合票ドラフト.md` に下書きあり）。
- **NG（実行不能）**：操作できず値を取得できなかった。画面の変更か試験側（ロケーター辞書・待ち）の問題。
- **ブロック**：前のケースが中断したため実行していない。前のケースの解決後に再実行する。
- **基準比**：`baseline.json`（既知の NG）と違う結果だけが終了コード 1 になる。

## 判定方法

- 画面操作は Playwright で実施。AI 指示文は標準辞書（core/locators.mjs の DEFAULTS）で固定ロケーターへ解決（モデル不要・サイト固有の辞書なし）。
- 合否は「DOM から記録した表示値」と「ポイント基盤 API への送信電文（/__test/ledger）」で判定。AI の目視判定（aiAssert）は参考（Playwright モードでは未実施）。
- 期待値は sites/coupon-demo/app/設計書.md による。スイートごとに /__test/reset で初期データへ戻す。
