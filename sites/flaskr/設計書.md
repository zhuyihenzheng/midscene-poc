# Flaskr 設計書（Flask 公式チュートリアルのアプリ）

試験対象は Flask 3.1.3 の公式チュートリアルで作るブログアプリ「Flaskr」。このフレームワークの作者が書いたものではない、実在のオープンソースのアプリに適用できるかを確かめるための対象。

- ソース：https://github.com/pallets/flask（タグ `3.1.3`）の `examples/tutorial`。`.ext/flask` に取得する（リポジトリには含めない）
- 仕様の根拠：Flask 公式チュートリアル（`docs/tutorial/*.rst`、https://flask.palletsprojects.com/en/stable/tutorial/）とアプリのソース。下の各項目に出典を書く
- 起動：`flask --app flaskr run --port 8096`（`examples/tutorial` で実行）。データは `instance/flaskr.sqlite`。`flask --app flaskr init-db` で空に戻る（database.rst）

## 画面一覧

| ID | 画面名（見出し） | URL | 出典 |
|---|---|---|---|
| S01 | Posts | `/` | `templates/blog/index.html` |
| S02 | Register | `/auth/register` | `templates/auth/register.html` |
| S03 | Log In | `/auth/login` | `templates/auth/login.html` |
| S04 | New Post | `/create` | `templates/blog/create.html` |
| S05 | Edit "{タイトル}" | `/{id}/update` | `templates/blog/update.html` |

全画面の上部（ナビゲーション）：ログイン前は「Register」「Log In」リンク、ログイン後はユーザー名と「Log Out」リンク（`templates/base.html`、templates.rst）。

## S02 Register・S03 Log In

- 入力項目：Username、Password。どちらも `required` で、空のままではブラウザが送信させない（templates.rst「The input tags are using the required attribute here」）
- エラーは画面上部に表示する（`base.html` の `div.flash`）

| 画面 | 条件 | メッセージ | 出典 |
|---|---|---|---|
| S02 | Username が空 | Username is required. | `auth.py:60` |
| S02 | Password が空 | Password is required. | `auth.py:62` |
| S02 | 登録済みのユーザー名 | User {username} is already registered. | `auth.py:74` |
| S03 | 存在しないユーザー名 | Incorrect username. | `auth.py:97` |
| S03 | パスワード誤り | Incorrect password. | `auth.py:99` |

- 登録に成功すると S03 へ（`auth.py:77`、views.rst）
- ログインに成功すると S01 へ。ログアウトすると S01 へ（`auth.py:105,116`）

## S01 Posts

- 投稿を新しい順に表示する（`blog.py:23` ORDER BY created DESC、blog.rst）
- 各投稿：タイトル、「by {ユーザー名} on {YYYY-MM-DD}」、本文（`index.html`）
- ログイン中は見出しの横に「New」リンク。自分の投稿にだけ「Edit」リンク（`index.html`、blog.rst）

## S04 New Post・S05 Edit

- 入力項目：Title（`required`）、Body（任意。チェックするのは Title だけ：`blog.py:69-70`）
- Title が空のときのメッセージ：Title is required.（`blog.py:70,98`。ブラウザの `required` を外して送ると表示される：templates.rst）
- 保存すると S01 へ（`blog.py:81,108`）
- S05 は保存済みの Title・Body を表示する。見出しは「Edit "{タイトル}"」（`update.html`）
- S05 の〈Delete〉は確認ダイアログ「Are you sure?」を出し、OK で削除して S01 へ（`update.html`、`blog.py:125`）。キャンセルなら何もしない

## 権限

- 未ログインで S04・S05 を開くと S03 へ（`auth.py:24-25` login_required、blog.rst）
- 他人の投稿の S05 を開くと 403 Forbidden（`blog.py:55`）
- 存在しない投稿の S05 を開くと 404 Not Found、本文に「Post id {id} doesn't exist.」（`blog.py:52`）
